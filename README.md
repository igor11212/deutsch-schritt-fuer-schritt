# Deutsch Schritt für Schritt

Безкоштовний сайт для самостійного вивчення німецької мови від **A1 до C1**.
Пояснення граматики — українською, матеріал і завдання — німецькою.

**Сайт:** https://igor11212.github.io/deutsch-schritt-fuer-schritt/

## Що всередині

Рівень складається з **граматичних модулів** і **чотирьох модулів навичок**.

Граматичний модуль — три розділи:

| Розділ | Що містить |
|---|---|
| **Граматика** | Пояснення українською з таблицями, порівняннями та типовими помилками |
| **Вправи** | Вибір відповіді, пропуски, відповідності, порядок слів, richtig/falsch — з миттєвою перевіркою |
| **Тест** | Підсумковий тест модуля з підрахунком балів (прохідний — 60 %, як на іспиті) |

Модулі навичок — на весь рівень, а не на окрему тему:

| Модуль | Що містить |
|---|---|
| **Лексика** | Увесь словник рівня за темами: таблиці з перекладом і приміткою, озвучення слова й теми, режим флеш-карток |
| **Читання** | Тексти у форматі іспиту зі словничком і завданнями |
| **Аудіювання** | Діалоги й монологи, озвучені синтезом мовлення браузера, із завданнями і транскриптом |
| **Письмо** | Завдання у форматі Goethe / ÖSD: ситуація, пункти, корисні фрази, перевірка тексту, модельна відповідь |

Формати завдань відтворюють структуру іспитів **Goethe-Zertifikat** та **ÖSD**.
Проєкт неофіційний і не пов’язаний із цими інституціями.

## Технічно

Статичний сайт без збірки і без залежностей: HTML + CSS + ES-модулі.
Хеш-навігація (`#/a1/3/grammar`, `#/a1/wortschatz`), тому працює на GitHub Pages без додаткових налаштувань.
Вміст рівня довантажується динамічним `import()` лише тоді, коли ви його відкриваєте.

**Аудіювання** використовує Web Speech API браузера — жодних аудіофайлів і жодних запитів у мережу.
Для якісного звучання потрібен німецький голос у системі:

- **macOS** — Системні налаштування → Спеціальні можливості → Вимовлений вміст → Голоси системи → додати Anna / Markus
- **Windows** — Параметри → Час і мова → Мова → Додати німецьку (з пакетом мовлення)
- **Android / iOS** — налаштування синтезу мовлення, додати німецьку

Якщо німецького голосу немає, сайт показує підказку, а всі тексти залишаються доступними в транскриптах.

### Локальний запуск

ES-модулі не працюють через `file://`, тому потрібен будь-який локальний сервер:

```bash
python3 -m http.server 8000
```

Далі відкрийте http://localhost:8000

### Публікація на GitHub Pages

1. Створіть репозиторій на GitHub і завантажте вміст цієї теки в його корінь.
2. Settings → Pages → Build and deployment → Source: **Deploy from a branch**.
3. Branch: `main`, папка `/ (root)` → Save.
4. За хвилину сайт буде доступний за адресою `https://<нік>.github.io/<репозиторій>/`.

Файл `.nojekyll` уже додано — він потрібен, щоб GitHub Pages не обробляв теку через Jekyll.

### Кеш після оновлення

GitHub Pages віддає файли з `cache-control: max-age=600`, тож браузер тримає стару версію
десять хвилин. Щоб зміни було видно одразу, всі внутрішні адреси мають версійну мітку
`?v=РРРРММДДx` — у `index.html`, у кожному `import` всередині модулів і в динамічному
завантаженні рівнів.

**Після будь-якої зміни коду чи контенту підніміть мітку** — інакше частина відвідувачів
побачить стару версію:

```bash
grep -rl "?v=" index.html assets | xargs sed -i '' "s/?v=[0-9a-z]*/?v=$(date +%Y%m%d)a/g"
```

Мітку треба ставити на **кожен** специфікатор import, а не лише на точку входу: браузер
кешує кожен URL модуля окремо.

### Як додати модуль

Відкрийте файл потрібного рівня і додайте об’єкт у масив `modules`:

```js
{
  id: 'm3',
  title: 'Назва німецькою',
  titleUk: 'Підзаголовок українською',
  can: ['після модуля ви зможете…'],
  grammar:   [{ title: '…', html: '<p>…</p>' }],
  exercises: [ /* вправи */ ],
  listening: [{ exam: '…', title: '…', instruction: '…', lines: [{ speaker: '…', de: '…', uk: '…' }], tasks: [] }],
  writing:   [{ exam: '…', title: '…', situation: '…', points: [], minWords: 40, phrases: [], checklist: [], model: '…' }],
  test:      [ /* вправи */ ],
}
```

Таблиці в `html` можна писати звичайним `<table>` — рушій сам додасть стилі й горизонтальний скрол.

Лексики в модулі **немає**: словник живе у `data/vocab-<рівень>.js` і має вигляд

```js
export const groups = [
  { group: 'Назва теми', note: 'за яким принципом упорядковано',
    items: [{ de: 'das Wort', uk: 'слово', ex: 'примітка або приклад' }] },
];
```

Слова всередині теми впорядковані **логічно, не за абеткою**: числа за зростанням,
дні тижня від понеділка, прикметники парами протилежностей. Той самий порядок
використовують і флеш-картки, якщо вимкнути перемішування.

### Типи вправ

```js
{ type: 'choice',    q: 'Питання', options: ['a','b'], answer: 0, explain: '…' }
{ type: 'multi',     q: '…', options: [...], answers: [0, 2] }
{ type: 'truefalse', q: '…', answer: true, labels: ['Richtig','Falsch'] }
{ type: 'gap',       q: 'Ich ___ Anna und ___ aus Kyjiw.', answers: ['heiße', 'komme'] }
{ type: 'match',     q: '…', pairs: [['der Tisch','стіл']], speak: false }
{ type: 'order',     q: '…', words: ['Ich','komme'], answer: 'Ich komme' }
```

Поля `explain` (пояснення після перевірки), `hint` (підказка) і `audio` (текст для кнопки 🔊)
можна додати до будь-якої вправи. У `gap` і `order` кілька правильних варіантів
розділяються вертикальною рискою: `'heiße|heisse'`. Перевірка нечутлива до регістру,
розділових знаків і приймає `ae / oe / ue / ss` замість умлаутів.
